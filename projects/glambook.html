GlamBook — Beauty Appointments

  • PHP
  • Bootstrap
  • jQuery

Overview

GlamBook is a custom booking system for Glamorosa Beauty Parlour. It was built with PHP, AJAX, jQuery, and Bootstrap so clients can book appointments and staff can manage the schedule from an admin panel.

What I built

  • Real-time booking so appointment requests update without a full page reload.
  • An admin panel for managing services and staff.
  • A mobile-friendly Bootstrap interface for clients booking from their phones.
