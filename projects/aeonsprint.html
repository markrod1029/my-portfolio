Overview

Aeonsprint Tech is a Laravel and Vue.js web app that presents the company’s services. The interface is split into modular components and laid out with responsive Bootstrap so more features can be added later without rebuilding the site.

What I built

  • A service showcase organized into reusable Vue components.
  • A Laravel backend that keeps the pages and data structure easy to extend.
  • A responsive Bootstrap layout that works across screen sizes.
